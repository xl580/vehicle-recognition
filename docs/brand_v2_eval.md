# 品牌识别 v2：开放词表检索 + 文本先验融合

> 目的：解决 v1「线性探针只认 49 个美欧日韩品牌，中国品牌一个都不认识」的问题。
> 结论：**不改任何模型权重**，通过「图像检索 + 文本零样本」融合，街拍 Top-1 从 18.8% 提升到 56.2%，中国品牌从 0% 提升到 45.5%。

## 1. 问题定义

v1 的品牌判别是 49 类闭集线性探针。闭集分类器的本质缺陷：**词表外的类永远学不出来**，
遇到比亚迪/理想/蔚来只能在 49 个错误答案里取 argmax，而且往往给出很高的置信度。

## 2. 评测集（自建，可复现）

| 项 | 内容 |
|---|---|
| 来源 | Wikimedia Commons，`scripts/fetch_brand_photos.py` 自动抓取 |
| 规模 | 24 品牌 / 143 张**真实街拍**，每品牌 5–6 张 |
| 组成 | 12 个中国品牌（BYD、Geely、Chery、Wuling、NIO、Li Auto、XPeng、Changan、Hongqi、Haval、MG、Roewe）+ 12 个 v1 已覆盖品牌做对照 |
| 协议 | **留出法（leave-one-out）**：每品牌留 2 张做查询（共 48 张），其余 95 张进参考库 |

选留出法而不是「拿 Stanford 棚拍当库、街拍当查询」，是因为后者测量的是**域偏移**，
而本方案要验证的是「加一个新品牌只需几张实拍图」——留出法才是真实使用方式。

## 3. 三种方案对比（同一批 48 张查询）

| 方案 | 全部 Top-1 | Top-3 | 中国品牌 Top-1 | 海外品牌 Top-1 |
|---|---|---|---|---|
| v1 线性探针（闭集 49 类） | 16.7% – 20.8% | — | **0.0%** | 16.7% – 20.8% |
| 图像检索（CLIP B/32 + 原型中心） | 41.7% | 62.5% | 36.4% | 46.2% |
| 文本零样本（多 prompt 平均） | 52.1% | 62.5% | 40.9% | 61.5% |
| **融合（z-score 后 0.5 : 0.5）** | **56.2%** | **70.8%** | **45.5%** | **65.4%** |

三点值得注意：

1. **中国品牌 0% → 45.5%**：这是本方案最核心的收益。没有训练任何东西，仅靠参考图和品牌名文本。
2. **文本侧比图像侧强**（52.1% vs 41.7%）：CLIP 在预训练时见过大量「品牌名 + car」的图文对，
   对品牌名的语义先验很强；而图像侧受限于只有 4 张参考图 + 街拍背景干扰。
3. **融合好于任一单路**（56.2%）：两路错误模式不同——文本错在形近品牌（Geely/Chery），
   图像错在视觉相似车型，z-score 对齐后加权互补。

## 4. 视图消融（图像检索单路）

| 视图组合 | Top-1 | Top-3 | 说明 |
|---|---|---|---|
| 整图 + 翻转 + 中心 75% 裁剪 | 39.6% | 58.3% | 基线 |
| 上述 + YOLO 车身裁剪 | 35.4% | 56.2% | **变差**：整图背景稀释了车身信号 |
| YOLO 车身裁剪（含整图） | 41.7% | 58.3% | 用检测框替代盲裁 |
| YOLO 车身框中心 55%（前脸/格栅） | 41.7% | **62.5%** | 品牌线索最密集的区域 |

结论：**给 CLIP 喂「车身/前脸」比喂「整张街拍」好**，但提升幅度在 48 张查询下约等于 1 张图，
属于噪声量级，不宜过度解读。真正有效的是换判别方式（文本先验、融合），不是调视图。

## 5. 反向实验：换更强的自监督特征

试了 **DINOv2-small**（`--backbone dinov2`）替代 CLIP 提特征：Top-1 仅 **25.0%**，明显更差。

原因：品牌是**语义概念**（"这是比亚迪"），不是纯视觉相似性。DINOv2 是自监督学习，
特征里没有语言监督带来的品牌语义，在「同品牌不同车型」这种"视觉差异大、语义相同"的场景反而吃亏。
**这个负结果值得保留**——它说明选 CLIP 不是随手选大模型，而是任务性质决定的。

## 6. 局限（诚实声明）

1. 仅 48 张查询，1 张 = 2.1%，±4% 以内都是噪声，不要拿小数点后一位说事
2. 图源单一（Wikimedia，多为欧洲街景），未覆盖夜间/雨雪/遮挡/远距离
3. 参考图 4 张/品牌偏少，真实部署建议 10–20 张/品牌，指标还会涨
4. 未做车标（logo）检测与分类——这是品牌识别最有潜力的下一步，预期能把 Top-1 推到 70%+
5. 品牌词表需人工维护（中英文别名，如 `Li Auto` / `理想`），目前靠品牌名本身匹配，未做别名归一

## 7. 复现命令

```bash
# 1. 抓街拍评测图（24 品牌，含 12 个中国品牌）
python scripts/fetch_brand_photos.py --per-brand 6

# 2. 留出法：图像检索 / 文本零样本 / 融合
python scripts/brand_gallery.py --mode zs  --src test_images/brand_photos --holdout 2 --views face
python scripts/brand_gallery.py --mode loo --src test_images/brand_photos --holdout 2 --views face

# 3. 视图消融
python scripts/brand_gallery.py --mode loo --src test_images/brand_photos --views det

# 4. 换骨干
python scripts/brand_gallery.py --mode loo --src test_images/brand_photos --views face --backbone dinov2
```

## 8. 落地建议（优先级）

1. **把融合方案接进推理流水线**：`weights/brand_gallery.npz` + 文本原型，低于阈值输出 top-3 候选并标注「无法确定」
2. 参考图扩到 10–20 张/品牌，覆盖白天/夜间/侧后 45°
3. 上车标检测（YOLO 检测 logo 区域）作为第三路证据
4. 若仍不够，再用真实数据微调 ResNet50/ConvNeXt 做闭集分类，与开放词表方案并存（词表内走分类，词表外走检索）
